This page contains important information for developers of 3rd party software who wish to utilise NEXDOC digital services within their own software offerings.
Software Development Packages
This table provides details of the software development packages for the NEXDOC system. The referenced packages contain the NEXDOC software development guide and all associated material needed to integrate 3rd party software with the NEXDOC system. Developers of 3rd party software should download and unzip the version which is appropriate for their scenario. Superseded versions are for historical reference only and should not be used for integrating with NEXDOC.
If you are a newcomer to NEXDOC and your software is not yet integrated, we highly recommend that you contact us so that we can assist you. See the Getting Assistance section for information on how to contact us.

Definitions
Publication Date: The date of the release of the referred version of the development package to the developer community.
Vendor Date: The date of the release of the NEXDOC system containing the features and functions as documented within the referred version, to the vendor test environment.
Live Date: The date of the release of the NEXDOC system containing the features and functions as documented within the referred version, to the live environment.
Major Version:   Contains major new features, non-backward compatible or breaking changes.
Minor Version:  Adds or changes functionality and/or fixes whilst retaining full backward compatibility.
Proposed Status: Pertaining to a version of the system which is under current or future development & testing.
Current Status: Pertaining to the current version of the system.
Superseded Status: Pertaining to a previous version of the system.
