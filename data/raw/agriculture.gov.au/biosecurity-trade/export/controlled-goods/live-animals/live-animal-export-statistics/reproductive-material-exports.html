The yearly figures are updated once all data has been received for the reporting period.

Figures represent number of reproductive units exported comprising Embryos, Semen, Pellets, Straws & Vials.

The Excel spreadsheet will allow you to download data and develop your own reports. The figures provided in the spreadsheet are the total numbers exported by species, destination and type of containment unit. The following fields have been provided to allow you to develop a variety of reports:

  • State of loading
  • Port of loading
  • Destination country
  • Species
  • Unit
  • Type
  • Quantity
  • Month of export
  • Year of export
  • Financial year of export.

The Excel spreadsheet is updated monthly. Figures are subject to change as more data becomes available.

To generate the data you are interested in, please download the Excel file and select the filter drop down arrow located in the grey highlighted header.

Please note: you are able to use multiple filters at one time – for example:

  1. Select the drop down arrow in Species and select Equine
  2. Select the drop down arrow in Type and select Semen
  3. Select the drop down arrow in Unit and select Straws
  4. Select the drop down arrow in Year and select 2022.

These filtered fields will then provide you with the number of equine semen straws that have been exported in 2022.

To clear any filtered selections, click on the Sort & Filter button in the top right corner of the ribbon and then select Clear.
